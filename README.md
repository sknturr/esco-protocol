# ЭСКО: чтение данных

ЭСКО-Т, ЭСКО МТР-06 и ТМ-3Э используют схожий двоичный протокол: запросы по 14 байт, одинаковые правила внешней контрольной суммы, команды чтения EEPROM/RAM, часов и архива по дате. Даты и накопленные значения кодируются BCD. Потребление вычисляется по соседним архивным интеграторам.

МТР-06 и ТМ-3Э имеют общую архивную карту: три и два контура соответственно. От ЭСКО-Т они отличаются картой памяти, размером архивной записи, форматом текущих значений и чтением текущих интеграторов.

## Различия приборов

| Параметр | ЭСКО-Т | ЭСКО МТР-06 | ТМ-3Э |
|---|---|---|---|
| Теплосистемы | Одна; описаны две магистрали | До трёх контуров, по две магистрали | До двух контуров, по две магистрали |
| Архивная запись / полный ответ | 64 / 69 байт | 256 / 261 байт | 256 / 261 байт |
| Архив по дате | `A/4`, типы 0/1/2 | `A/4`, типы 0/1/2 | Как МТР-06 |
| Альтернативное чтение архива | Для версии <3: `L`, восемь блоков по 8 байт | `A/1`, одна страница 256 байт | Как МТР-06 |
| Текущие значения | `G`, FP3 | `G`, FLOAT4 BE; шаг контура `0x58` | Карта МТР-06, требует проверки |
| Текущие интеграторы | `P/1/G`, номер значения | `R`, EEPROM `0x0100..0x01F8` | Карта МТР-06, требует проверки |
| Архивные объёмы V1/V2 | Отсутствуют | Есть для каждого контура | Как МТР-06 |
| Идентификация | EEPROM `0x0010`: каналы и исполнение | Тип `0x60`, бит `0x40` версии статистики сброшен | Тип `0x60`, бит `0x40` установлен |

Параметры запроса `A/4` одинаковы, но размер ответа и декодер записи выбираются по прибору. Декодеры текущих значений и карты ошибок также различаются.

## Соглашения

Смещения начинаются с нуля. Адреса с `0x` и байты пакетов — hex; остальные числа — десятичные. `BA` — физический сетевой адрес.

Общая карта МТР-06/ТМ-3Э относится к стандартной 256-байтовой архивной записи с типом `0x60`. Особые схемы и версии статистики могут иметь отличия. Текущие значения ТМ-3Э по карте МТР-06 пока не проверены на приборе.
