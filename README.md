# ЭСКО: чтение данных

ЭСКО-Т и ЭСКО МТР-06 используют схожий двоичный протокол: запросы по 14 байт, одинаковые правила внешней контрольной суммы, команды чтения EEPROM/RAM, часов и архива по дате. Даты и накопленные значения кодируются BCD. Потребление вычисляется по соседним архивным интеграторам.

Различаются карты памяти, размер архивной записи, формат текущих значений и способ чтения текущих интеграторов.

## Различия приборов

| Параметр | ЭСКО-Т | ЭСКО МТР-06 |
|---|---|---|
| Теплосистемы | Одна; описаны показания двух магистралей | До трёх независимых контуров, по две магистрали |
| Архивная запись / полный ответ | 64 / 69 байт | 256 / 261 байт |
| Архив по дате | `A/4`, типы 0/1/2 | `A/4`, типы 0/1/2 |
| Альтернативное чтение архива | Для версии <3: `L`, восемь блоков по 8 байт на запись | `A/1`, одна страница 256 байт на запрос |
| Текущие значения | `G`, собственный формат FP3 | `G`, IEEE-754 FLOAT4 big-endian; смещение контура `0x58*(n-1)` |
| Текущие интеграторы | `P/1/G`, отдельный номер каждого значения | `R`, 32 блока EEPROM `0x0100..0x01F8` |
| Архивные объёмы V1/V2 | Отсутствуют | Есть для каждого контура |
| Текущее состояние | `M 0x0028` | `G` по базовому адресу каждого контура |
| Идентификация | EEPROM `0x0010`: число каналов и исполнение | EEPROM `0x0010`: тип `0x60`; отдельно маска включённых контуров |

Параметры запроса `A/4` одинаковы, но размер ответа и декодер записи выбираются по прибору. Декодеры текущих значений и карты ошибок также различаются.

## Соглашения

Смещения начинаются с нуля. Адреса с `0x` и байты пакетов — hex; остальные числа — десятичные. `BA` — физический сетевой адрес.

Карта МТР-06 относится к стандартной 256-байтовой записи прибора с типом `0x60`. Особые схемы и версии статистики могут иметь отличия.
